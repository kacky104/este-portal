
# 「駅ちかから反映」のとき — 駅ちかに入れたセラピストは、フクエスにどこまで来るか
自動で動きます。出勤の取り込みと同じ周（15〜60分ごと）で、駅ちかの名簿を見に行きます。流れる先はフクエスだけです。

| 項目 | フクエスへ |
|---|---|
| 駅ちかに新しく入れた方 | フクエスにも自動で作られます（公開・NEW付き）。※ この自動作成は運営が店舗ごとにONにします |
| お名前 | 作るときに写します。あとで駅ちかで変えても、フクエスの名前は変わりません |
| 年齢・サイズ | 毎回写します（駅ちかで変えると、次の周でフクエスも変わります） |
| 写真 | 来ません。フクエスは仮の画像のままなので、フクエスで写真を上げてください |
| キャッチ・紹介文 | 来ません。フクエスで書いてください |
| 出勤・即ヒメ | 上の早見表のとおり（出勤は15〜60分ごと・即ヒメは出勤と一緒） |
| 駅ちかで消した方 | フクエスからは消えません。「セラピスト一覧」に「いません」と出るので、フクエスで退店にしてください |
| エステ魂・エステラブ・エスラン | 何も流れません（駅ちかとフクエスの間だけの取り込みです） |
・駅ちかの名簿にいる方とフクエスの方は、番号（駅ちかの管理番号）で結びつけて見分けます。番号がまだ無い方はお名前で見分けます
・同じお名前の方が2人以上いると、どちらか分からないので自動では触りません（「セラピスト一覧」で結びつけてください）

# 「フクエスから反映」のとき — フクエスのセラピストは、各サイトにどこまで行くか
自動では動きません。「セラピスト一覧」でその方の行の「駅ちかへ登録」「エステ魂へ登録」を押し、送る内容を確かめて「登録する」を押した1人だけを送ります。

| 項目 | 駅ちか | エステ魂 | エステラブ | エスラン |
|---|---|---|---|---|
| 送れるか | 送れます | 送れます | 送れません（エステラブが書き込みを止めています） | 準備中（まだ作っていません） |
| お名前 | 写します | 写します（10文字まで） | ✕ | ― |
| 年齢・身長・3サイズ・カップ | 写します | 写します（バストが空だと、エステ魂の公開ページに出ません） | ✕ | ― |
| 特徴（バッジ） | 駅ちかの「ジャンル」に置き換えます。当てはまる言葉が無いものは送りません（1つも無ければ「店長オススメ」） | エステ魂の「特徴タグ」に置き換えます（4つまで。1つも無ければ「新人」） | ✕ | ― |
| 写真 | 1枚目だけ1枚（トップ画像になります） | 1枚目だけ1枚（トップ画像になります） | ✕ | ― |
| キャッチ・紹介文 | 送りません（向こうの管理画面で書いてください） | 送りません（向こうの管理画面で書いてください） | ✕ | ― |
| 新人マーク | 付きます（30日で自動で消えます） | 付きません（特徴が1つも無いときだけ「新人」タグが入り、自動では消えません） | ✕ | ― |
| 向こうでの公開 | すぐ公開されます（フクエスで非公開の方でも） | すぐ公開されます（フクエスで非公開の方でも） | ✕ | ― |
| 登録のあと | 向こうの名簿を自動で読み直し、一覧に「います」と出ます | 向こうの名簿を自動で読み直し、一覧に「います」と出ます | ✕ | ― |
| あとでフクエスで直したもの | 追いかけません（名前・写真・年齢は向こうの管理画面で直してください） | 追いかけません（名前・写真・年齢は向こうの管理画面で直してください） | ✕ | ― |
| フクエスで非公開・退店にした方 | 向こうには残ります（駅ちかからの削除は運営にご依頼ください） | 向こうには残ります（エステ魂での非表示は運営にご依頼ください） | ✕ | ― |
・登録できるのは「フクエスから反映」にしているサイトだけ。「どのサイトにも反映しない」の枠には登録も名簿の読み取りもしません
・同じお名前の方がすでに向こうにいると送りません（二重登録を作らないため）。すでに番号が結びついている方も送りません
・「◯◯の名簿を読み直す」は、向こうに誰がいるかを見るだけです。フクエスには何も書きません（フクエスへの取り込みは駅ちかだけ）
