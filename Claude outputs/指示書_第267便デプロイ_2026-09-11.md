## 2. ★★★★★★ いちばん大事な直し ── 番号を【先に】書く（★ 第249便と同じ）

```
登録が通った瞬間、相手にはもう人が居る
  → そのあと写真の段で止まることがある（ctk 切れ・仮置き失敗・照合外れ）
  → もし番号を流れの最後に書いていたら、結びつきが書かれないまま終わる
  → ★★★ 次に同じ人を送ろうとして【もう1人作る】（二重掲載・禁則269）
```

→ ★★★★★★ `castCreateAfterList` の verify 枝で、`kind:'next'` でも **`mediaCreated` を返す**。
　★ 番人で固定済み（登録⑤c）。★ 変異試験: この1行を消す → **NG 1**／繋ぎを外す → **NG 8**。
